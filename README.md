# Atlas de Medicina · UCES

Atlas de estudo feito por alunos do 2º ano de Medicina da UCES: resumos, figuras interativas, perguntas guiadas, mini-quiz e cartões de revisão, em português e espanhol.

**Abrir:** https://pdroarraes-creator.github.io/uces-medicina/

- O progresso (cartões, revisões, quiz) fica só no navegador de cada aluno.
- Para instalar no celular: abra o link no Chrome → menu ⋮ → "Adicionar à tela inicial".
- Os resumos seguem o Costanzo, *Fisiología* (6ª ed.). As figuras são desenhos próprios, simplificados.

**Aviso:** material de estudo entre colegas. Não substitui o livro, as aulas nem o material oficial da cátedra. Confira sempre com a fonte oficial.
